6	A가 물을 쏟음	물을 마시려 함 → 실수함 → 쏟음 → 바닥이 젖음	옆에 있음 → 놀람 → 물에 젖음 → 닦아야 함
7	A가 블록을 무너뜨림	재미있게 놀고 싶음 → 신남 → 블록을 건드림 → 탑이 무너짐	열심히 쌓음 → 놀람/속상 → 탑이 무너짐

특히 아이에게 좋은 5가지 핵심 유형

이 게임을 만들 때는 위 35개를 똑같은 형태로 만들기보다 아래 5가지 상황 유형을 반복적으로 경험시키는 게 좋아.

① 내가 하고 싶은 것 vs 친구가 하고 싶은 것
→ “나는 하고 싶지만 친구는 싫을 수 있어.”

② 내 행동 → 친구의 감정 → 친구의 행동 → 나의 결과
→ 원인과 결과의 연결.

③ 친구가 거절했을 때
→ “싫어” → 내 감정 → 내가 할 수 있는 다른 행동.

④ 충동이 생겼을 때
→ “하고 싶다” → 멈춤 → 생각 → 행동 선택.

⑤ 같은 상황을 A/B 두 관점에서 보기
→ 이게 가장 중요해.
“누가 맞아?”가 아니라 “A는 왜 그렇게 했을까?” / “B는 왜 그렇게 했을까?”를 묻게 만드는 거야.

그리고 클로드 코드에 만들게 한다면, 나는 각 상황마다 단순히 질문만 넣기보다 게임 엔진 자체를 아래 구조로 고정시키는 걸 추천해.

상황 그림 → ① 무슨 일이 일어났어? → ② A는 왜 그랬을까? → ③ A는 어떤 기분일까? → ④ 그래서 A에게 무슨 일이 생겼을까? → ⑤ B는 왜 그랬을까? → ⑥ B는 어떤 기분일까? → ⑦ 그래서 B에게 무슨 일이 생겼을까? → ⑧ 다음에는 어떻게 하면 좋을까?

그리고 정답을 하나로 고정하지 말고 “가능한 이유”를 2~3개 제시하게 하면 훨씬 좋아. 예를 들어 “A가 B를 밀었어. 왜 그랬을까?”에 화가 나서 / 빨리 가고 싶어서 / 장난으로처럼 여러 가능성을 보여주는 식이야.
